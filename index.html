Setup Guide

Start in 5 Minutes

No installation wizard needed. Just download, run, and you are ready.

1
Step 1 — Download
Download the Software
Click the green Download button above. Your browser will download a ZIP file from Dropbox. Save it anywhere — your Desktop, Downloads folder, or a USB drive.
PharmacyERP.zip → Save to Desktop
2
Step 2 — Extract & Run
Extract and Launch
Right-click the ZIP file → "Extract All" → open the extracted folder → double-click PharmacyERP.exe to launch. No installation required. If Windows SmartScreen appears, click "More Info" → "Run Anyway".
PharmacyERP.exe → Double Click to Run
💡 .NET 8 Runtime required. Download free from microsoft.com/dotnet if prompted.
3
Step 3 — First Time Setup
Fill Your Pharmacy Details
On first launch, the Setup Form will open automatically. Enter your pharmacy name, address, city, phone number, and NTN/STRN (for receipts). Also set the Print Header — this text appears on top of every customer receipt.
📋 Example print header: "AL-SHIFA PHARMACY · Model Town, Lahore · 0300-1234567"
4
Step 4 — Secure Your Account
Create Your Admin Password
Set a strong password for the Admin account. You can also create Manager and Cashier accounts with different permission levels. Managers can approve voids; Cashiers can only operate the POS. You can change your password anytime from Settings → Change Password.
5
Step 5 — Printer Setup
Configure Your Printers
Go to Settings → Local Config. Set your Receipt Printer Name (default is POS-58 for 58mm thermal printers) and your Barcode Printer Name (default is ZDesigner for Zebra printers). Use the exact Windows printer name from your Printers & Scanners settings.
🖨️ Common printer names: "POS-58", "EPSON TM-T20", "Xprinter XP-58", "ZDesigner GK420d"
✓
Ready!
You're All Set — Start Selling
Open your first shift from the Shift menu, add your medicines in the Inventory section, and start using the POS Terminal. Press F12 to process a cash sale, F11 for Khata, F3 to search medicines. Everything is keyboard-friendly for fast pharmacy counter work.
